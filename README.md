# Win Win 7.4 – Großer Aktivkatalog-Sprint

Version 7.4 erweitert den direkt nutzbaren Katalog um **48 neue aktive Gewinnspiele**. Insgesamt enthält die App jetzt **278 Katalogeinträge**, davon **199 am 10.08.2026 aktiv**. Der Quellenpool umfasst **295 verifizierte Quellen**.

## Qualitätsregeln

Weiterhin ausgeschlossen: Social-only, Teilnahme ausschließlich per Radio-Anruf, Kauf- oder Kassenbonpflicht, Club-only sowie iamstudent. Newsletter-Anmeldung ist nur dort enthalten, wo sie kostenlos und ohne Kauf/Club-Mitgliedschaft möglich ist.

## Statussicherheit

Bestehende IDs wurden nicht verändert. Abgelaufene Einträge bleiben zur Statusstabilität erhalten. Favoriten, „Teilgenommen“, „Nicht interessant“, Gewinne, Historien und weitere lokal gespeicherte Nutzerstatus werden bei Updates nicht überschrieben.

## Technik

`contests.json`, eingebetteter Offline-Fallback, Quellenkatalog, Service-Worker-Cache, Manifest und Versionsinformationen sind auf 7.4 synchronisiert.
